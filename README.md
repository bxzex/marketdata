# Market Data

Look up stocks, ETFs and international symbols by typing to it like a chat.

Live: https://bxzex.github.io/marketdata/

Data comes from the Financial Modeling Prep API. You'll need your own key from them if you run it yourself. Put it in `INTERNAL_KEY` in `src/App.tsx`.

React, TypeScript and Tailwind. `npm install` and `npm run dev` to start it.
